## 🔑 About This Project

In this project, we build a Dark / Light Theme using HTML and CSS while practicing important front-end concepts such as Flexbox, the Box Model, and CSS variables.
It’s a great hands-on project for strengthening your understanding of HTML & CSS and learning how to create a clean, user-friendly interface with different color themes.

🎬 Video tutorial for this project is available on our [Youtube Channel](https://youtube.com/playlist?list=PLltyZsSwXMdFKILc5aXbG7fMTtRzBUld4&si=Q0FS9ISF3ZD26PN9).
